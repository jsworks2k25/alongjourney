# Game Design Document — A Long Journey · 扎根式 (Rooted Edition)

> 这是 `**GDD.md`（旅程式）** 的对照版本。
> 主旨相同：现有代码资产做一款"建造 / 塔防 / 收集 / 探索"的求生游戏。

---

## 1. 一句话定位 / Elevator Pitch

> **《A Long Journey》是一款建造 / 塔防 / 收集 / 探索游戏。**


---

## 2. 核心机制

1. **火是这片大陆的底层逻辑**，篝火/火炬，目前的想法：火可以笼罩一片有限的区域，使得玩家可以安全地探索，也许可以加强我方单位
  - 添火：扩大火的照明范围+可安全探索区域
2. **你很弱**
  - 你的战斗能力很有限，需要围绕基地和防御建筑来抵御入侵
  - 
3. **一日之内决定一切**
  - 一天 = 一个完整决策单元：**白天去哪 / 夜里守哪**。不做长达数天的连续任务。
  - 设计后果：远征要有"今天回不回得来"的张力；夜潮节奏紧凑（5–8 分钟）。

---

## 3. 核心循环 / Core Gameplay Loop

### 3.1 一日循环（10–15 分钟）

```text
 - 白天探索、收集、建造
 - 黄昏回来
 - 晚上抵御怪物
```

### 3.2 长程循环（一局，约 4–8 小时）

- 地图被划分为 **5×5 = 25 个区块**，中心 1 块是家园，外围 24 块从迷雾中逐步揭开。
- 每揭开 N 块解锁一个**世界观节点**（残骸、广播、壁画）。
- 当玩家备齐"信号塔"所需的稀有材料（来自最外环的 4 个 boss 区块），即可在家园组装信号塔，进入**终局之夜**。
- 终局之夜 = 一场拉长的夜潮 + 信号塔启动剧情 → 通关。

---

## 4. 玩家旅程 / First-Hour Experience


| 时长            | 玩家在做                           | 我们想教他什么          |
| ------------- | ------------------------------ | ---------------- |
| **0–3 min**   | 醒来、跟随光点找到一片空地、点燃篝火（首个存档锚点）。    | 移动、交互、家园锚定。      |
| **3–10 min**  | 砍树、采石、做出第一面**围栏**和一个**箭塔**。    | 收集 → 建造 → 防御 三连。 |
| **10–18 min** | 第一个白昼远征：走出 1 格迷雾，遇到 NPC 求救事件。  | 远征循环、风险/回报。      |
| **18–25 min** | 第一夜潮：2 波 Ghost 沿固定边缘涌入。        | 塔防核心、值夜分配。       |
| **25–30 min** | 黎明结算 → 看到家园视觉变化（多了一缕烟、多了一个人影）。 | "家园在长大"的情感反馈。    |

## 5. 玩法系统 / Gameplay Systems（精简版）

> 优先级：**P0 = MVP 必须 / P1 = 首发应有 / P2 = 之后再说**。

### 5.1 操作 (P0)

- 沿用现有方案：WASD 移动、鼠标点击交互/攻击、数字键热栏、`B` 进入建造模式、`M` 打开地图。

### 5.2 地图 — 区块 + 迷雾 (P0 核心)

- **固定 5×5 区块**（共 25 块），中心 1 块为家园起点。
- 每块约 30×30 瓦片，**手作 + 资源点随机化**（不做完全程序化）。
- 迷雾覆盖未探索区块，远征推开。
- 4 个角块 = boss 区，藏有信号塔稀有零件。
- **理由**：固定大小是抑制沙盒膨胀的最强工具，比任何"自我克制"都管用。

### 5.3 收集与背包 (P0)

- 沿用 `InventoryComponent` + 5 格热栏 + 家园**储物箱**作为永久库存。
- 远征**只能带 5 格**回家 —— 制造"今天带啥回去"的取舍。
- 主资源：木材、石头、废金属、布料、电池、**信号晶体**（稀有，仅 boss 区）。

### 5.4 建造 — 三类、纯外部 (P0 核心)

> **关键约束：与旅程式版本一致 —— 不做建筑内部空间。**

1. **生活节点**：篝火（存档）、储物箱、床（NPC 居住，决定人口上限）、信号塔（终局）。
2. **生产链**：伐木场、石场、工坊、发电机。生产链通过**短传送带 / 工人路径**连接（P1）。
3. **防御**：围栏、箭塔、陷阱、探照灯（揭迷雾外环）。

设计原则：

- 建造**永久保留**，但有**维护需求**（夜潮会破坏，需修复）。
- **不做装饰物件**（地毯、画框、灯具…）—— 这是规模失控的常见入口。
- **不做建筑等级升级**（v1 → v2 → v3）—— 改成"解锁新建筑"，扁平展开。

### 5.5 战斗与夜潮 (P0)

- 沿用现有 Ghost / Robot + 1 个 Boss（每个 boss 区一个，共 4 个；MVP 只做 1 个）。
- 夜潮从地图**边缘固定刷怪点**涌入家园，路径可被防御工事分流。
- 玩家角色定位：**塔的补漏者 + 紧急救援**（与旅程式同）。
- 死亡：在家园**床位**复活，丢失远征背包；村民可能阵亡（永久）。

### 5.6 NPC 与同伴 (P1，但情感地位很高)

- **远征事件**救回的 NPC 成为村民，每人 1 个工种（樵夫 / 工程师 / 神枪手 / 治疗）。
- 工种带 AI 自动行为：白天工作、夜晚值夜或避难。
- **人口上限 = 床位数，最多 5 人**。规模硬约束。
- 村民有**简短台词 + 黄昏闲聊**，传递世界观（不做长对话树）。

### 5.7 科技 / 蓝图 (P1)

- **一条主线（信号塔升级路径） + 3 条短分支（路线流 / 陷阱流 / 同伴流）**。
- 解锁来源：远征带回特定残骸、村民工种解锁、boss 战利品。
- 科技树**节点总数 ≤ 25**，硬上限。

### 5.8 世界观叙事 (P1)

- 全部走环境叙事：远征中的残骸、广播片段、壁画、村民只言片语。
- 主线疑问：**这片地为何空了？信号塔的另一端是谁？**
- MVP 不需要完整答案，留到首发版本。

### 5.9 多人 (P2)

- 同旅程式：协作 Co-op，单局共享一个家园；MVP 单人。

## 6. 美术与氛围 / Art & World

> 与旅程式版本**完全共用**。一份美术资产可同时支撑两版玩法。

- 等距 2D 像素，4 向 + 镜像。
- 低饱和冷色 + 火光暖色高光。
- 家园的**视觉成长**是重点：起点是孤独的篝火，终局是窗口透着灯光的小村落。
- UI 极简：热栏 + 血量 + 当日时间条。

---

## 7. 范围控制 / Scope（这一节是规模可控的命门）

### 7.1 ✅ MVP（垂直切片，目标：可玩到第一个 boss）

- 5×5 地图，**只激活中心 + 周围 8 块 = 9 块**，外圈 16 块在 MVP 锁定。
- 1 个 boss + 2 种普通敌人。
- 5 种资源 + 8 种合成产物。
- 生活节点 4 个、生产链 3 个、防御 4 个 = **共 11 个建造物件**。
- 1 名可救援 NPC + 1 个工种。
- 完整一日循环 + 3 个夜潮。

### 7.2 🟡 首发应有

- 25 块全开，4 个 boss。
- 4 个工种、人口上限 5。
- 信号塔终局流程。
- 25 个科技节点。
- 控制器支持。

### 7.3 🔴 明确不做 / Out of Scope

> 扎根式最容易膨胀，这一节比旅程式更重要。

- ❌ **建筑内部空间 / 室内场景**。
- ❌ **装饰物件系统**（地毯、画框、灯笼、家具皮肤）。
- ❌ **建筑等级升级**（v1→v2→v3）。
- ❌ **农耕系统**。
- ❌ **天气 / 四季**（夜潮即唯一周期）。
- ❌ **村民关系系统**（婚姻、好感度、礼物）。
- ❌ **复杂工业链**（多层流体、电路逻辑）。
- ❌ **村庄外观自定义 / 旗帜 / 涂装**。
- ❌ **PVP / 入侵其他玩家村庄**。
- ❌ **无限沙盒模式 / 创造模式**。
- ❌ **DLC 式的"新生态扩展"**（圈定 1 个生态，做深不做广）。

## 9. 风险与对策 / Risks


| 风险              | 影响     | 对策                             |
| --------------- | ------ | ------------------------------ |
| **沙盒膨胀（玩家想装修）** | **极高** | §7.3 的不做清单；建造物件**总数硬上限**。      |
| 一张大地图调试地狱       | 中      | 区块化、每块独立场景；先做 9 块原型。           |
| 终局拖沓（找不到信号塔零件）  | 中      | 信号塔零件位置**固定可见在地图上**，迷雾掀开就知道在哪。 |
| 村民 AI 复杂度爆炸     | 中      | 工种 AI = 状态机 + 工作点列表；不做需求模拟。    |
| 玩家情感绑定后死亡惩罚过重   | 中      | 村民阵亡是叙事高光（带短追悼），不是惩罚。          |

## 10. 待决问题 / Open Questions

> 这些是**只在扎根式版本**里需要拍板的问题（其余通用问题见旅程式 GDD §11）。

1. **家园是否会被攻破？**
  - A. 永远不会被推平，最坏是建筑全损坏 —— 玩家心理负担小。 *(推荐 MVP)*
  - B. 篝火被毁 = game over，可重开。
  - C. 篝火被毁 = 永久存档结束（roguelike 化）。
2. **远征是否分日计算？**
  - A. 每次远征必须在黄昏前回家，否则在野外承受**夜外惩罚**。 *(推荐，制造紧张感)*
  - B. 可以在外野营过夜，多日远征。
3. **村民死亡是否永久？**
  - A. 永久 —— 情感重量足，但玩家会 SL。 *(推荐)*
  - B. 受伤休养，永不真死。
4. **建造维护机制？**
  - A. 防御工事**夜潮会损坏需修**，生活/生产节点不会。 *(推荐，集中点)*
  - B. 全部需要维护 —— 真实但繁琐。
  - C. 都不需要维护。
5. **信号塔终局后？**
  - A. 直接通关 + 致谢，存档归档。 *(推荐 MVP)*
  - B. 解锁"新游戏+"，难度提升。
  - C. 解锁创造模式 / 沙盒延续。**(违反 §7.3，不推荐)**

## 11. 选哪一版？/ Decision Aid

如果你回答下面这些问题更多偏 A，走 **扎根式**；更多偏 B，走 **旅程式**。


| 问题                | A（扎根）      | B（旅程）        |
| ----------------- | ---------- | ------------ |
| 我想让玩家**最难忘的一刻**是… | 回到家园看到村落变大 | 走到山脊看到下一段地平线 |
| 我团队**美术产能**更适合…   | 把一种生态做深    | 做几种生态各做浅     |
| 我**怕的开发风险**更是…    | 节奏断层       | 沙盒失控         |
| 我希望玩家**重玩动机**来自…  | 沙盒微调与挑战难度  | 随机化的旅程内容     |
| 我希望**叙事节奏**是…     | 慢慢拼凑、家园温度  | 阶段性揭幕、戏剧推进   |
