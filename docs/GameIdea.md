# 游戏想法

目前的设计
2d的等距视角，像素瓦片

动画可能做2或4向，左右翻转

操作：点击、拖拽放置、方向键移动

玩法
建造、塔防、收集、探索

体验感：
来到一个未知的世界，一开始感到孤独、荒凉、寂静，通过探索慢慢了解世界观，并且可以建造、收留npc、抵御敌人、发展基地（科技或防御建筑）等增强信心

世界观：
也许是后启示录，一个看似普通的野外，但也许是若干年后，类似“无尽之剑”

地图：
生成式，生态群落（类泰拉瑞亚/mc）

建造：
还不确定规模
不确定建筑内部和外部是否是分开的空间

最小开局：
做一个篝火/帐篷（存档点）

灵感来源：泰拉瑞亚，我的世界，部落冲突，环世界，星露谷物语，饥荒，僵尸毁灭工程，mindustry

头脑风暴：

世界观的体现：
文明留存了痕迹但人消失了 — 玩家会发现废弃的建筑、残留的机器、甚至未完成的建设，暗示"之前有人在这里"，但没有解释。
敌人不是怪物，是某种"系统" — 环境本身在排异。比如黑暗、腐化、某种蔓延的东西。让玩家觉得不是在打仗，是在抵抗。（越来越长的黑夜、更短的白天？）
NPC有自己的故事 — 每个人有一句话的背景。玩家慢慢拼凑世界观。比如我们探索时发现了一个npc，他可以通过背景自我介绍让我们了解世界观和指引。

或许可以结合“搜打撤”，变为“搜造撤”，在一个地方停留越久-敌人越强/环境生存难度越高-但奖励越丰厚-一旦失败沉没成本越高（投入更久的据点被毁/掉落物品）

纠结点：
是否要坚持2d等距：
    潜在美术制作挑战-可减少动画、
    透视：上下移动是左右的0.5倍，人物操控是否看起来怪；攻击距离，同样左右比上下看起来远，动画和判定怎样设计-可以不做人物进展攻击，主打塔防/简单射击
改俯视角：
    迁移快，现有素材多。
    人物操控更直观，是大多玩家的习惯，战斗比较好做。
    透视奇怪，是否展示建筑/人物侧面。
    同质化严重，太多俯视角2d游戏。
转3d管线：
    相机角度灵活，素材复用/大量素材库。
    透视舒服。
    时间投入未知，建筑等可能需要建模-lowpoly/混合现有资源/ai建模工具
    画面效果，渲染可用代码大幅提升，更能体现技术
